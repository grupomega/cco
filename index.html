Gestão dos links

Cadastre, altere, exclua, exporte e importe os links. As alterações ficam salvas neste navegador via localStorage. Para publicação online centralizada, use este HTML como menu principal e direcione os botões para outros sistemas, páginas, formulários e dashboards.

Atenção: na versão HTML puro, cada navegador salva seus próprios links. Para todos verem os mesmos links automaticamente, publique uma lista central JSON ou conecte a página a banco de dados/API.
